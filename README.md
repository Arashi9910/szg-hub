# 上漲谷中控

把所有 Chrome 設定檔裡的遊戲角色資料集中到一個面板：**總覽、裝備（可自訂篩選）、資源總表、交易助手**。
不會碰帳號密碼；資料只存在你自己的電腦（`data/state.json`），不會上傳到 GitHub。

## 自動更新（v0.6 起全自動）

- **伺服器與面板**：每 2 分鐘到 GitHub 檢查一次；有新版而且沒有工作在執行，就自動更新並重啟（約 5 秒）。不想自動的話，取消面板右上角的「自動更新」，改成手動按「立即更新並重啟」。更新前會做語法檢查，舊版備份在 `backup` 資料夾。
- **竄改猴腳本**：Tampermonkey 裡裝的是「載入器」，功能程式（`agent.js`）用 `@require` 從中控伺服器載入。**每個設定檔要做一次設定**：Tampermonkey 圖示 →「控制台」→「設定」→ 設定模式改「進階」→「Externals」→「Update Interval」改成「Always」。之後伺服器有新版時，遊戲頁面會在 2 分鐘內自動重新整理並載入新程式（有工作在跑時會等它結束）。沒設定的話，面板總覽頁會提示是哪幾個設定檔。
- 版本號只有一個：面板右上角的「伺服器 vX」就是全部（伺服器、面板、腳本）的版本；Tampermonkey 清單顯示的數字會在它每日檢查時跟上。
- `start.bat` 本身不會自動更新（Windows 不允許執行中的 .bat 被覆蓋）。

## 一、第一次安裝

1. **裝 Node.js**：到 https://nodejs.org 下載 LTS 版並安裝（一路下一步）。
2. **啟動伺服器**：到 https://github.com/Arashi9910/szg-hub 按「Code → Download ZIP」，解壓縮到固定位置（例如 `D:\szg-hub`），雙擊 `start.bat`（啟動中控）。
   出現黑色視窗並顯示「上漲谷中控已啟動」就成功了，**玩的時候讓它開著**。
3. **每個 Chrome 設定檔都要做一次**：
   1. 安裝 Tampermonkey（竄改猴）擴充功能。
   2. 到 `chrome://extensions` → Tampermonkey →「詳細資料」→ 打開 **「允許使用者指令碼」**（新版 Chrome 一定要開，不然腳本不會跑）。
   3. 伺服器開著的狀態下，在網址列打開 `http://127.0.0.1:8787/szg-hub.user.js` → Tampermonkey 跳出安裝畫面 → 按「安裝」。
   4. Tampermonkey「設定」→ 設定模式「進階」→「Externals」→「Update Interval」改成「Always」。
4. **打開遊戲**：遊戲頁面右下角出現綠色的「中控：已連線」就代表在回報資料了。
5. **打開面板**：用任何一個瀏覽器打開 http://127.0.0.1:8787

## 二、使用重點

- **同帳號的第二隻角色**：遊戲只會給目前角色的完整資料，所以每個帳號的另一隻角色，要在遊戲裡「換角色 → 切換」一次才會出現在面板上。之後就會一直保留（顯示最後更新時間）。
- **EXP%、每小時經驗、交易 ID**：這三個是從畫面上讀的。打開過主控台（EXP%、每小時經驗）和人物頁（交易 ID）各一次之後就會記住。
- **灰色列**：超過 5 分鐘沒更新，通常是那個設定檔的遊戲分頁沒開。
- **本尊**：在總覽點 ★ 設定。資源頁的「收集清單」會列出本尊以外每隻角色身上的楓幣、卷軸、道具和裝備數量。
- **升級時間**：總覽「升級還要」欄用目前每小時經驗算出升下一級要多久；上方填「目標等級」會多一欄「到 LvX」。每級需要的經驗由腳本回報精確值、自動累積成經驗表（總覽「經驗表」可看現在 vs 原版的倍率）；還沒收集到的等級用原版經驗 × 最接近等級的倍率估算，標「估計」。
- **楓幣收入**：總覽讀數列的「楓幣收入／時」是掛機中角色的每小時楓幣加總，「合計賺得」是所有角色本次掛機賺的楓幣（下面附遊戲的累計賺得）；角色表格「每小時楓幣」欄可排序。數字來自遊戲主控台的掛機報告（本次賺的楓幣 ÷ 掛機時間），這次掛不到 10 分鐘的先不算每小時。

### 裝備頁
- **穿戴對照**：每隻角色一列、每個部位一欄，列出全部素質；「部位設定」裡這個部位要看的素質會加粗（v0.36 起，跟浮動判斷同一份設定）。
- **裝備清單**：穿戴、背包、倉庫的裝備全部列在一起，可以依部位、位置、職業需求、角色、名稱、需求等級、強化次數、剩餘可衝次數、**任意素質條件**（可疊加多條）篩選，點表頭排序。
  - 設好的條件按「存成組合」，下次從下拉選單直接套用。
  - 「可穿的角色」會列出職業和等級符合的角色（還沒算能力值需求）。
  - 上方可切換「目前（含衝卷）」和「原始（未衝卷）」素質。

## 三、常見問題

| 狀況 | 處理 |
|---|---|
| 右下角顯示「連不到本機伺服器」 | 確認 `start.bat` 的黑色視窗有開著 |
| 右下角完全沒有出現提示 | 確認 Tampermonkey 已開啟「允許使用者指令碼」，而且腳本是啟用狀態 |
| 想重置所有資料 | 關掉伺服器，刪除 `data` 資料夾再重新啟動 |
| 8787 埠被占用 | 用記事本打開 `start.bat`，把 `PORT=8787` 改成別的數字，腳本裡的 `HUB` 也要一起改 |

## 四、讓公司電腦（或其他電腦）也回報到家裡的中控

家裡設定檔的腳本**都不用改**；本機連線不需要通行碼。

1. **兩台電腦都裝 Tailscale**（https://tailscale.com ），用同一個帳號登入。
2. **家裡電腦**改用 `start-remote.bat` 啟動（取代 `start.bat`）。
   第一次啟動時 Windows 防火牆會詢問 → 按「允許」。小黑窗會印出一行
   `http://100.x.x.x:8787/remote.user.js?token=...`
3. **公司電腦**：Chrome 裝好 Tampermonkey、打開「允許使用者指令碼」後，
   直接在網址列貼上第 2 步那行網址 → Tampermonkey 會跳出安裝畫面 → 按「安裝」。
   連線位址和通行碼都已經自動填好。
4. 公司電腦打開遊戲，右下角出現「中控：已連線」就完成了。

補充：
- 在公司也想看面板：打開 `http://100.x.x.x:8787/?token=通行碼`。
- 通行碼存在家裡的 `data\token.txt`。外流的話刪掉這個檔案再重啟伺服器，會換一組新的（公司那份要照第 3 步重裝）。
- 公司電腦顯示「連不到中控伺服器」：確認家裡電腦開著、用的是 `start-remote.bat`、Tailscale 兩邊都是已連線。還是不行的話，在家裡電腦用系統管理員身分開 PowerShell 執行：
  `New-NetFirewallRule -DisplayName "szg-hub" -Direction Inbound -Protocol TCP -LocalPort 8787 -RemoteAddress 100.64.0.0/10 -Action Allow`
  （只開放 Tailscale 網段連 8787 埠）

## 五、交易助手（v0.3 起）

面板的「交易」分頁：

- **收集（分身 → 本尊）**：勾選分身，按「建立收集工作」。會帶走背包裡可交易的道具、背包裝備、楓幣（預留 5% 手續費）。
  固定排除：穿在身上的裝備、補給設定使用中的藥水、已鎖定的物品、倉庫內的東西。也可以自己加排除的道具名稱。
- **給某隻角色（v0.36 起在背包）**：到「背包」勾選物品（可以跨好幾隻角色）→ 底部「給…」，在側邊抽屜選收的人、改每樣數量、另外加楓幣；只轉楓幣按「轉楓幣…」。交易頁只留「收集」。
- 超過 20 格會自動拆成多次交易；同一種道具超過 9999 個會拆成多份，分到不同批次（遊戲每格上限 9999）。
- **工作佇列**：工作建立後是「待確認」，核對明細再按「確認執行」。執行時雙方的遊戲分頁都要開著，並切到指定角色；右下角會顯示交易進度。

安全設計：
- 收貨方只接受工作清單上指定帳號的邀請，並且逐項核對對方放的東西；有任何不在清單內的東西就自動取消。
- 放東西前會再檢查一次鎖定狀態和伺服器的可交易清單（二次檢查）。
- 任何一步卡超過 3 分鐘會自動取消，工作標成「失敗」，可以按「重試」從失敗的那一批繼續。
- 同帳號的兩隻角色不能互相交易，請用倉庫。

篩選器（收集、背包都有）：
- **道具類別**：卷軸／消耗／其他…，都不勾＝全部。
- **指定道具**：「只要這些道具」「排除這些道具」兩個下拉選單，列出你所有角色背包裡實際有的道具（依類別分頁、可搜尋、顯示總數），勾選即可。
- **裝備**：全部背包裝備／不含裝備／套用「裝備」頁存好的篩選組合（部位、職業、素質條件）。

## 六、背包操作（v0.5 起）

- **v0.36 整理**：背包只負責角色身上的東西（賣、鎖、給角色）；背包和公倉之間搬東西統一在「公倉」分頁。上方「角色」用共用選擇器（全部／A 組／B 組／有分頁的／自訂），類別順序跟公倉一樣（裝備、卷軸、消耗、其他）。
面板的「背包」分頁：選角色 → 用篩選器縮小範圍 → 勾選 → **賣出選取／鎖定選取／解鎖選取**。
三種看法：**條列**（一件一列，看得到每件裝備的掉落浮動和判斷；表頭「物品／在誰身上／判斷」可以排序）、**依道具**（同名合併、列出誰有多少）、**依角色**（像遊戲背包的格子）。
工具列的「浮動」篩選可以只看「浮動達標／未達標／算不出」的裝備；條列裡有「選取畫面上浮動未達標、沒鎖定的裝備」一鍵選取，再按賣出。
「全選可賣的（一鍵全賣）」會勾選篩選結果中有售價的道具與未鎖定的背包裝備。
一樣要在工作佇列按「確認執行」才會動作；賣出時會再跳過鎖定的物品與補給中的藥水，並在報價項目比選擇的多時自動停止。

**第一次使用建議先小量測試**：在背包選一個道具按「給…」數量改 1，確認流程正常再做大量收集。

## 自動化總表與共用設定（v0.36 起）
- 總覽「自動化」（v0.37 起是滑動開關，一按就開關；撿到裝備自動處理、自動上架開啟時會先問要直接執行還是試跑）列出所有自動功能（掛機續掛、撿到裝備自動處理、公倉自動存入、市場掃描、自動上架、領攤位收益、知識王、遊戲自動販售、中控更新），顯示開／試跑／關和最近一次動作，點一下跳到設定。
- 所有「套用的角色」都是同一個選擇器：全部／A 組／B 組／有分頁的／自訂。前四種會自動跟著角色變動（新角色、切換分頁）。
- **部位設定**：每個部位、每種武器判斷浮動要看哪些素質（預設：物理武器看物攻、法杖看魔攻、防具和飾品看四屬）。裝備頁、背包、公倉、撿到自動處理、自動上架都用這一份。撿到自動處理和自動上架的條件可以選「浮動達標（1＝是）」「浮動分數」，規則裡有「＋ 保留浮動達標的」一鍵加上。

## 知識王共享題庫（v0.38 起）
- 所有人的中控一起累積題庫：答完題遊戲公布的正確答案會自動上傳到共享題庫（Google 試算表＋Apps Script），每 30 分鐘下載一次別人累積的；遇到題庫沒有的題目會馬上再抓一次。
- 只上傳遊戲公布的正解（自己在面板猜的不傳），只送題目、選項、答案和一組匿名編號，不送角色名稱、帳號。
- 同一題有不同答案時，以最多不同中控回報的為準，同票先不提供；每個中控同一題只算一票。題庫優先順序：自己學到的 ＞ 共享題庫 ＞ 內建 ＞ 冒險資料庫。
- 預設加入；知識王頁「加入共享題庫」開關可以關掉。想自己架一份：把 `tools/quiz-share.gs` 貼到自己的 Google 試算表（擴充功能 → Apps Script），部署成網頁應用程式（執行身分：我、存取：所有人），把網址填到「進階：改用自己的題庫網址」。

## 七、掛機控制（v0.8 起）

總覽頁上方「掛機控制」：
- 在表格左邊勾選角色（每個帳號的第二隻角色也可以勾，不用切換），按 **▶ 開始掛機／Ⅱ 暫停掛機／↻ 重新開始**（重新開始＝先暫停再開始，24 小時重新計算）。按下去幾秒內就會生效，不需要確認。
- **自動續掛**：到期前 N 分鐘自動重新開始；已經到期停掉的也會自動開始。從面板按「暫停掛機」的角色不會被重新開始。
- **掛滿 N 小時自動暫停**：開啟時不會自動續掛。
- 表格每列「自動」取消勾選，就不套用自動規則。
- 需要那個帳號的遊戲分頁開著才會執行；「自動處理紀錄」可以看到做過什麼。

## 八、公會倉庫（v0.32 起公開版也有）
- 「公倉」分頁（v0.35 改版）：
  - 上方**狀態列**：公倉名稱、道具／裝備容量（快滿變橘、滿了變紅）、楓幣、點數、自動存入狀態和規則摘要，右邊三個按鈕：重新整理、存入規則、楓幣／點數。
  - 下面**左邊背包、右邊公倉並排**，上方的類別（卷軸／消耗／其他／裝備）和搜尋兩邊一起篩。左邊點選要存的（可以只看某隻角色、A 組或 B 組；裝備有「選達標的／選未達標的」），按中間「**存入 →**」；右邊點選要領的，選「道具領給」誰（裝備照每件的「給誰」，已依職業等級建議），按「**← 領取**」。兩個方向都可以再搬回來，所以按了就直接執行。不要的公倉裝備可以「賣掉」：由指定角色領出後馬上賣給商店。
  - **存入規則**（側邊抽屜）：自動存入（先試跑）、依規則手動存一次、快速套用、哪些角色、整類／個別、裝備浮動條件、浮動判斷基準、保留數量。
  - 第一次使用時上方會出現設定引導，完成後自動收起。
- **浮動判斷基準（v0.34 起）**：每個部位、每種武器看的素質不同。預設：物理武器看物攻、短杖／長杖看魔攻、防具和飾品（含手套）看力量、敏捷、智力、幸運；分數＝這些素質的掉落浮動加總，分數 ≥ 門檻（預設 1）＝達標。可以在「存入規則」或背包工具列的「浮動判斷基準」改，公倉、背包共用同一份。存入規則的條件選「依部位基準達標」就會各部位分開判斷。
- **楓幣、點數（v0.34 起）**：④ 切換「存入公倉」或「從公倉提領」。存入：每隻角色填要存的楓幣（點數是帳號共用，每個帳號一列），可以「每隻保留 N，其餘全部存」快速填入。提領（v0.34.1）：在要拿到錢的角色那一列填金額，合計不能超過公倉餘額，會被扣公會稅（面板先估算，實際拿到多少寫在工作紀錄）。建立的工作要在「工作」確認（單一或「全部確認」都可以，全部確認前會列出金額再問一次）；執行前先讀公倉、確認餘額夠，做完把公倉和身上的餘額變化寫進紀錄。自動存入永遠不碰楓幣和點數。
- 同一個帳號兩隻角色都有背包工作時，目前角色的先做，另一隻等切換。

## 九、同一個帳號開兩個分頁（v0.33 起）
- 遊戲分頁右下角「＋ 開 某某 的分頁」，或直接再開一個遊戲分頁（自動換成沒有分頁的那隻），開一個新視窗固定顯示另一隻（網址 `?szgChar=角色ID`，腳本在載入前改好就拿掉）。兩隻同時在線：資料即時，工作交給各自的分頁。
- 中控用各分頁每 3 秒的輪詢判斷「哪隻有分頁」（總覽標「分頁」）；沒有分頁的角色＝背景掛機，工作會等它有分頁。已經有分頁的角色不能被切換。
- 同一隻開兩個分頁：後開的暫停中控功能。市場（掃描、攤位、自動上架）每個帳號只由一個分頁做；知識王一次只讓一個分頁作答。
